values[0]

[1, 2, 3]

6. Very Important Difference

Look at these two:

values.push()
values.push([7, 8, 9]);

Adds a new row:

[1,2,3]
[4,5,6]
[7,8,9] ← new row
values[0].push()
values[0].push(7);

Adds an element to row 0:

[1,2,3,7] ← modified row
[4,5,6]

So remember:

2D Array

values.push([7,8,9])
       ↑
   adds a row


values[0].push(7)
         ↑
    adds to row 0
7. Example with push() and pop()
let values: number[][] = [
    [1, 2, 3],
    [4, 5, 6]
];

// Add a new row
values.push([7, 8, 9]);

// Add an element to row 0
values[0].push(10);

// Remove last element from row 1
values[1].pop();

console.log(values);

Result:

[
  [1, 2, 3, 10],
  [4, 5],
  [7, 8, 9]
]
Easy rule

For a 2D array, array.push() / array.pop() operate on rows, while array[row].push() / array[row].pop() operate on elements within that row.
