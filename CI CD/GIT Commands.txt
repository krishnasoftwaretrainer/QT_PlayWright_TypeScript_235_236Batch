Push Files into Branch

Step1: Create a New Branch
Local Branch: Created and stored in your local repository
Remote Branch: Stored on a remote server

Step2: Switch to It
git checkout -b newbranch  [your branch name]
Switched to a new branch 'newbranch'

Step3:Verify:
git branch	[Lists only local branches]
git branch -r	[Lists only remote-tracking branches]
git branch -a 	[Lists all branches — both local and remote]

You should see:
$ git branch -a
  app1
  feature-login
* kkk
  master
  remotes/origin/HEAD -> origin/master
  remotes/origin/master
  remotes/origin/newbranch
  master

Step4: Stage the File
git add File4.html   Or add all changes:
git add .

Step4: Commit the Changes
git commit -m "Added file to newbranch"
